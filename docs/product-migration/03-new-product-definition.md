# 03 — New Product Definition

## One-liner

AI discovers issues people care about on the internet, structures them as short cards, and lets users express an opinion and see others’ takes.

## Loop

```text
Information → AI Issue → Card → Participation
```

Not: AI news dump · finance portal · SNS · Polymarket clone · X clone.

## MVP success question

> When a user sees an AI Issue card, do they want to express their view and see what others think?

## North-star metric (design for)

`Participation Rate = participants / Issue viewers`

Also track: impression, open, comment rate, return visit.

## MVP does

1. Shared multi-source ingest → cluster → Issue
2. Issue Feed (Home)
3. Issue Card + Detail
4. One-tap participation (binary / choice / sentiment — AI picks type; no forced debate)
5. Simple comments + like
6. Aggregate participation counts

## MVP does not

Follow graph, DM, friends, points, real money, prediction market, reputation systems, heavy gamification, HTS charts, full Reddit threads.

## Positioning vs Market Radar

| Was | Becomes |
| --- | --- |
| “What matters in my market today?” | “What are people talking about — and what do you think?” |
| Signal for investors | Issue for curious participants |
| Brief listen-first | Card read + participate |
| Stock watchlist personalization | Shared trending Issues (Topic follow later) |
